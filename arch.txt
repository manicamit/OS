🔌 How Rust ↔ C will talk (ABI contract)

This is critical — get this right once and you’re golden forever.

From C → Rust
// c_side.h
void vmm_map_page(uint64_t virt, uint64_t phys, uint64_t flags);

#[no_mangle]
pub extern "C" fn vmm_map_page(virt: u64, phys: u64, flags: u64) {
    unsafe { VMM.lock().map_page(virt, phys, flags); }
}

From Rust → C
extern "C" {
    fn ahci_init();
}


Zero overhead.
No wrappers.
No runtime cost.
